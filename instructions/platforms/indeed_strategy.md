# Indeed Application Strategy

## Objective
Maximize application volume on Indeed using their Quick Apply system.

## Search Strategy
1. Go to Indeed.com.
2. Search for titles like "Frontend Developer" or "Software Engineer".
3. Filter results by **Date Posted**: Last 24 hours.
4. Filter by **Easily apply**.

## Execution Flow
1. Click through the search results list.
2. Click **Apply now**.
3. Use the Indeed easy apply modal. The system often pre-fills data.
4. For custom employer questions, reference `/personal_data/form_answers.md`.
5. Review and Submit.
6. Log to `/tracking/applied_jobs.csv`.

## Exclusions
- If an Indeed application requests a mandatory custom skills test or assessment before submission, skip it.
