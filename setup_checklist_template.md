# Local Setup Checklist

> This file is runtime state and is intentionally ignored by Git. Checked boxes are only reminders; the agent must verify the actual files and saved values on every `start`.

## Required personal files
- [ ] `personal_data/resume.pdf` exists.
- [ ] `personal_data/profile.md` exists and has no unresolved placeholders.
- [ ] `personal_data/form_answers.md` exists and has no unresolved placeholders.
- [ ] `personal_data/credentials.md` exists when company-portal credentials are required.

## Saved profile topics
- [ ] Basic/contact information saved.
- [ ] Employment history and current role saved.
- [ ] Education saved.
- [ ] Current/expected salary includes amount, currency, and period when available.
- [ ] Notice period saved.
- [ ] Job titles, locations, and accepted work modes saved.
- [ ] Work authorization and sponsorship saved in `profile.md`.
- [ ] Common screening answers saved.

## Application readiness
- [ ] Selected platform sign-ins are ready when needed.
- [ ] Company career URLs saved when `company_direct` is selected.
- [ ] Existing company accounts are recorded separately when needed.
- [ ] No application starts while any required setup item is unfinished.

## Verification
- [ ] Actual files and values were rechecked; checklist boxes alone are not proof.
- [ ] Setup is complete only after the agent confirms all required checks pass.
